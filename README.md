# Мереживо KYIV — стартовий проєкт

## Що є в цій версії
- Адаптивний мобільний інтерфейс.
- Серверний проксі до публічного JSON API YASNO (Київ: regionId=25, dsoId=902).
- Пошук вулиці, будинку, групи та отримання графіка на сьогодні/завтра.
- Кеш API на 4 хвилини, щоб не створювати зайве навантаження.
- PWA manifest для подальшого встановлення на головний екран.

## Запуск локально
Потрібен Node.js 20 або новіший:
```bash
npm start
```
Відкрити http://localhost:3000

## Публікація
Розгорнути як Node web service на Render/Railway/Fly.io. Build command не потрібна, start command: `npm start`. Після розгортання додати власний домен за бажанням.

## Важливі обмеження
Це інтеграційний прототип, а не підтверджений production-сервіс. Публічний API може змінити схему, вимагати додаткові параметри або тимчасово бути недоступним. Перед публічним запуском необхідно перевірити фактичні відповіді всіх address endpoints і протестувати кілька адрес, включно з будинками, де кілька груп або немає прогнозу. Якщо API не повертає дані — інтерфейс не повинен вигадувати графік.

Офіційна сторінка для ручної звірки: https://www.dtek-kem.com.ua/ua/shutdowns
